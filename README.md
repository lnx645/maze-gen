# 🌀 Generator & Solver Labirin

Generator labirin acak (algoritma *recursive backtracker*) + solver dengan animasi
**BFS** dari titik start (hijau) ke finish (merah), digambar di canvas.

Fitur:
- Tombol **🔀 Generate Ulang** — labirin baru 21×21 yang selalu punya solusi
- Tombol **🧭 Solve (BFS)** — animasi penjelajahan BFS, lalu jalur terpendek
  digambar kuning beserta jumlah langkahnya

## Cara Menjalankan

Buka file `index.html` langsung di browser:

```bash
xdg-open index.html
# atau buka manual lewat browser: File → Open
```
